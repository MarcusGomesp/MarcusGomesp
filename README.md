## Olá, eu sou o Marcus 👋

Sou **Marcus Vinicius Gomes Pereira**, **Analista de Operações Digitais II** na **Capgemini** e estudante de **Ciência da Computação na UNINOVE**, direcionando minha carreira para o **Desenvolvimento Back-End com C# e .NET**.

Nos meus projetos, desenvolvo APIs REST, implemento regras de negócio e integro serviços para resolver problemas como controle de inventário, gestão de banco de horas e análise de currículos em um contexto acadêmico.

Gosto de transformar processos manuais em soluções organizadas, práticas e confiáveis. Minha abordagem é **entender o problema, construir uma solução e documentar seu funcionamento**.

## O que meus projetos demonstram

- Desenvolvimento de APIs REST com C# e ASP.NET Core
- Implementação de operações CRUD, cadastro e autenticação de usuários
- Organização em camadas, com separação entre endpoints e regras de negócio
- Persistência de dados com SQL Server e Entity Framework Core
- Integração de APIs externas e tratamento de respostas de IA
- Importação, sincronização e exportação de dados em Excel e CSV
- Fluxos de solicitação e aprovação para gestão de ponto e banco de horas
- Documentação com Swagger e testes de integração via Postman
